## Como executar

Use um JDK. Há módulos com configuração do IntelliJ IDEA para JDK 24. Na IDE, abra a pasta da atividade e execute uma classe com método `main`.

Para executar o exemplo de tabuada diretamente no terminal, parta da raiz do repositório:

```bash
cd "Molina - JAVA/JAVA/Atividade 1 - JAVA - Rec/src"
java Ativadade2tabu.java
```

O exemplo imprime as tabuadas de 5 e de 2, de 0 a 10.
